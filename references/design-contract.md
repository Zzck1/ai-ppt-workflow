# 轻量设计契约

完整制作、长稿或跨轮改稿时使用；已有清晰大纲时补齐缺项即可。记录放工作区，可用 Markdown 表格，也可采用 [可执行 JSON 样例](../examples/course-report.plan.json)。不要求用户填表，不为普通任务额外增加确认轮次。

## 四个阶段及交接

| 阶段 | 要解决的事 | 进入下一阶段的条件 |
| --- | --- | --- |
| 内容规划 | 谁听、听后理解什么、材料支持什么、每页说什么 | 约定总页数和顺序，结论有来源；关键缺口可见 |
| 制作准备 | 字体、色板、模板、图片、图表数据 | 所用工具真实可用，必需素材存在且许可适用 |
| 页面制作 | 按逐页消息表达，保留可编辑内容 | 每个计划页面均已制作，正文与图表同步 |
| 渲染与交付 | 检查实际最终 PPTX、修复并重验 | 结构检查与逐页视觉检查都有证据，剩余限制已说明 |

失败从所属阶段恢复：换图不重做事实研究，修正数值要同步所有引用页与图表；页数或顺序改变先更新规划。原稿另存、保留上一个可用版本。只有用户明确要求先确认的阶段才停下等待。

## 最小记录

- 受众、主结论和用途：现场讲解、课后阅读或兼顾；时间限制和总页数。
- 必须保留和不可改变项：原始数据、术语、用户指定顺序及模板。
- 画布与单位：用户模板优先；新横版课堂汇报可从 16:9 开始。像素、英寸、pt 不混用。
- 字体与色板：记录目标设备实际可用字体；例如标题 32pt、正文 24pt、注释 14pt 可作起点，按屏幕和密度调整。不要为塞字不断缩小；替换字体后重新渲染。记录背景、正文、强调色的 HEX 值，数据颜色保持同一含义。
- 每页消息：页码、标题、要传达的一句话、可见正文、来源 ID、视觉形式、备注；比较、顺序、层级等关系必须由材料支持。
- 素材记录：文件、来源、许可/授权状态、用途、裁切限制、是否已就绪。缺少必需素材时列明缺口，不将占位框称为成品。

跨页保持字体、图例、页码和引用规则一致；页面表达可随内容变化。课堂汇报可用问题→方法→证据→局限→回顾，不强迫每页三张卡片，也不添加无内容的过场页。纯文字或表格能说清时，无须生成图片。

## 事实到图表的交接

为重复引用的关键事实分配稳定 ID，如 F01。记录状态（fact / plan / scenario / pending）、数值、单位、期间、口径和来源位置。每页引用 ID，不另维护互相矛盾的数字副本。

图表记录类别、每个数据点对应的事实 ID、数值和单位；同一图表中不可把不同单位或期间悄悄合并。缺失值保留缺失，百分比保留分母，派生值保留公式和输入。脚本可检查 ID 和数值对应，但不能判断来源真假、结论是否合理、统计口径是否可比。

标题/正文/备注之间区分必见信息与讲述解释。影响结论的限制、模拟标记和来源不能只藏在不可见备注中。
