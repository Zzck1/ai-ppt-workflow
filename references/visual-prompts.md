# 视觉与提示词

按需阅读：普通配图用前四节；艺术字、视频或3D只读对应进阶节。示例变量跟随当前主题，不预置校园题材或固定绿色配色。

## 1. 先写素材需求

确定图片要解释什么、放在哪一页、横竖比例、主体位置、标题留白、风格和需要保留的对象。标题在左时，为图像主体安排右侧空间。页面中需要精确修改的文字、数字和数据标签留作原生文本。

一套素材共用色板、光线、线条、材质和视角规则。先选择或生成一张代表图，再做同系列变体。参考风格不等于照搬原图构图或复制原教程素材。

实际生成或编辑图片时，读取当前环境的图像生成技能并使用其支持的工具。不要把提示词文件交付成“已生成图片”。忠实记录实际输入参考图、提示词、输出文件与用途，便于后续复用。

按用途选来源：真实人物、产品、实验结果和历史证据优先使用可核验原图；概念、氛围或隐喻可用生成图，并避免暗示它是实拍证据。网络图片记录作者、原始页面、许可及署名要求；搜索结果、可下载 URL 和“免费”字样不能证明可复用。许可未核实时标为未核实，换用自制原生图形、用户已授权素材或许可明确的替代。保留原文件，裁切和抠图另存，不覆盖来源。

## 2. 封面与插画

### V01 封面配图

```text
为[主题]制作原创PPT封面配图，画幅[比例]。
场景：[与主题有关的具体环境]；主体：[物体、动作及数量]。
主体放在[位置]，保留[位置与大致比例]的连续干净区域用于后续排标题。
风格：[摄影／插画及关键特征]；配色：[色板]；光线：[描述]。
必须保留或满足：[约束]。不要出现：[不相关元素]。
不生成标题文字、数字、logo或水印；精确信息将在PPT中另加。
```

### V02 概念示意图

```text
制作解释[概念]的教学示意图，关系为：[部件、连接、流程方向]。
使用[画幅、视角、视觉风格]，保留空白供添加可编辑标签。
清楚区分[容易混淆的关系]，不补造未知部件或工程参数。
没有足够依据的部分不要画成确定的结构。
不包含文字、尺寸和品牌。此图用于概念说明，不是工程设计图。
```

对科学或工程示意进行关系核对，不能只检查画面美观。真实产品需要保留品牌或商标时遵循用户提供的素材，而不是通用“无logo”模板。

## 3. 原图编辑与透明素材

先检查用户图。将“可变化项”与“必须保持项”写清楚；有人手、文字、商标或精确产品外形时，额外检查这些区域。

### V03 清理与换背景

```text
以我上传的图片为输入进行编辑。
只修改：[背景、杂物或光线]。
保持：[主体数量、形状、比例、材质、颜色、位置、文字、相机视角等]。
删除：[明确指定的杂物]；背景改为：[描述]。
保留[标题区域]的干净留白，不新增物品或重设计主体。
输出[比例]，接触阴影自然，主体不悬浮。
```

### V04 提取透明素材

```text
从上传图片中提取[明确主体]，完整保留轮廓、颜色与可见结构。
删除背景，输出带真实alpha通道的PNG。
主体完整，边缘干净，四周留适量空白。
不绘制棋盘格，不改成白色背景，不增加物体、文字或水印。
```

检查真实 alpha 与边缘，并在深浅背景上查看。透明预览的棋盘格可能已经被画进图里。多图标合集只算风格预览，不能称为若干独立透明文件；最终需要独立素材时逐张交付。

## 4. 配色与排版

沿用用户指定风格。没有指定时，根据场景选背景、正文、强调色及少量辅助色，先保证对比与投影可读性。主题不要求绿色、米色或任何固定配色。

图文布局服务信息关系：左右对照表达差异，流程表达顺序，时间安排突出时间和责任，数据图保留单位与基准。装饰不要占据主要阅读空间。

修图一次只针对明确问题，如留白不足、背景杂乱、人物手部异常。不要以反复整图生成代替可控局部编辑；失败后根据已观察的问题调整方式。

## 5. 艺术字与3D

艺术字适合短标题装饰，需逐字核对和缩小检查；正文、日期与可变信息保留普通文本。不能识别的中文艺术字改为清楚字体加装饰素材，不把错字当作风格。

3D风格的 PNG/JPEG 是静态图。需要旋转或观察隐藏面时才进入模型制作，核实可生成的模型格式、材质和演示软件实际导入支持。仅凭单张外观图无法确认背面或内部结构，未知部分不要声称真实。没有模型工具时明确可以交付什么，不能改后缀冒充模型。

## 6. 动态封面

先核验是否有可用图生视频工具与时长支持；若用本地关键帧或合成制作，向用户说明制作方式。用户明确指定AI视频模型或产品时，不能把本地合成冒称为该模型输出。

### V05 克制的微动封面

```text
以我上传的原图制作约[时长]秒的[比例]横版视频。
镜头固定，不摇晃、不推近、不旋转、不切换场景。
保持[静止主体、人物、手部、物体]的数量、形状和位置基本不变。
保持[标题区域]干净，原有文字保持静止，不增加文字、人物、logo或物品。
只允许[具体区域的一项微动作]以及原场景柔和光影极慢地移动。
运动幅度小，不翻页、不变形、不重新生成交换或行走动作。
支持循环时让结尾接近开头，衔接平缓。
```

验收实际视频分辨率、时长、帧率和解码结果，抽查运动最大时刻与首尾帧。源图并非精确目标比例时选择轻微裁切或留边，保留关键主体；不要未经检查就称为标准16:9。对固定区域进行前后比较，同时保留静态封面备选。

默认不为静态 PPT 自动制作视频。视频文件能解码只证明文件可读；目标演示软件的实际播放与循环仍需在对应环境验证。
